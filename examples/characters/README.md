# Character presets

## 達妮婭｜鳴潮・繁體中文

`denia.zh-Hant.json` contains the character input fields used by the MVP API. This is an original, low-spoiler role-play configuration; opening dialogue and relationship phases are not official game dialogue or canon events.

- Language: Traditional Chinese (Taiwan/Hong Kong neutral usage).
- Scenario: a quiet encounter at the academy.
- Phases: 初識 → 熟悉 → 信任, manually selected per conversation.
- Background: published into character-scoped RAG.
- Memory: enabled, isolated per conversation.
- Provider/model: ChatGPT / `gpt-6-luna`, selected from the connected account's available models during setup. Other installations must choose a model their account can access.

Public references used for the short background summary:

- [Official news index — 達妮婭 character/archive announcements](https://wutheringwaves.kurogames.com/zh-tw/main/news)
- [Official combat demonstration](https://www.youtube.com/watch?v=wuHfT0S4s1w)
- [Public character-profile report](https://www.vgover.com/zh-tw/news/207316)
- [Pixivision character introduction](https://www.pixivision.net/zh-tw/a/11739)

The preset deliberately omits later plot revelations and unverified details. Its interaction instructions are written for this app rather than copied from another chatbot's character card. Test conversations use fictional preferences and remain separate from the user's fresh story.
